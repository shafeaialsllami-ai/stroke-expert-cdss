مشروع STROKE EXPERT CDSS لنظام Android

ما الذي تم تجهيزه؟
- مشروع Android Studio مبدئي يفتح نسخة HTML المحلية داخل WebView.
- تم نسخ index.html وmanifest.json وsw.js والأيقونتين 192 و512 إلى أصول التطبيق.
- لم يتم تعديل المحتوى السريري أو خوارزميات HTML.

تنبيه مهم حول العمل دون إنترنت:
هذه النسخة ليست بعد APK مكتملًا ومختبرًا دون إنترنت. ملف index.html الأصلي يستدعي:
1) Tailwind CSS من https://cdn.tailwindcss.com
2) Font Awesome من cdnjs.cloudflare.com

لذلك قد لا يظهر التنسيق والأيقونات بشكل صحيح عند انقطاع الإنترنت حتى يتم تضمين هاتين المكتبتين محليًا. لم تُحذف روابطهما أو تُستبدل بتخمينات. روابط إرشادات AHA وFDA الخارجية ستظل تتطلب الإنترنت عند فتحها.

طريقة فتح المشروع:
1. فك ضغط ملف ZIP.
2. افتح Android Studio ثم اختر Open وحدد مجلد STROKE-EXPERT-CDSS-Android-Project.
3. اسمح لـ Android Studio بتنزيل مكونات Gradle وAndroid SDK المطلوبة (تحتاج إنترنت أثناء الإعداد).
4. بعد اكتمال Sync اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. سيظهر APK عادةً في app/build/outputs/apk/debug/app-debug.apk.

لماذا لم أرفق APK جاهزًا؟
بيئة التجهيز الحالية لا تحتوي Android SDK أو Gradle ولا يمكنها تجميع APK هنا. كما أن الاعتمادين الخارجيين أعلاه يمنعان وصف النسخة الحالية بأنها تعمل بالكامل دون إنترنت.

السلامة:
هذا النظام أداة تعليمية لدعم القرار، وليس جهازًا طبيًا معتمدًا أو أمرًا علاجيًا. يجب التحقق من المحتوى والبروتوكولات محليًا وإجراء اختبارات متعددة التخصصات قبل أي استخدام سريري. لا تُدخل بيانات تعريفية للمرضى.
