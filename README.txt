STROKE EXPERT CDSS — Clinical Case 001
======================================

CONTENTS
- clinical-case-001.html : standalone, responsive case page
- README.txt             : these instructions

HOW TO USE
1. Extract this ZIP file.
2. Open clinical-case-001.html in a browser. It works offline.
3. To publish it with your existing GitHub Pages/Cloudflare Pages site, upload
   clinical-case-001.html to the same project folder as index.html.
4. The page will then be available at /clinical-case-001.html.

IMPORTANT
- This ZIP does not modify or replace index.html.
- Uploading the HTML file alone does not automatically add a navigation tab
  to the existing home page. A separate, small link/button change is needed
  if you want it visible in the site's navigation.
- Patient identifiers have been reduced to the supplied code W.A. Do not add
  names, phone numbers, addresses, hospital numbers, or other identifying data.
- Proposed medication changes are transcribed for review, not endorsed
  prescribing instructions. Independent clinical verification is essential.
